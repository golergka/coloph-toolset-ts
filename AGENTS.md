# Project instructions

Keep the library small. Use plain data and functions, strict TypeScript, Zod, and useful Effect utilities.
Keep context outside serialized arguments. The host owns access policy, persistence, and transactions.
Do not pursue feature parity with the independent Python coloph-toolset project.
Evaluate user ideas independently. If an idea has a material flaw, stop affected work, explain the problem, and propose an alternative.
Run `bun run check` before each ordinary commit. Preserve 100% source coverage and test public contracts, including failure cases.
